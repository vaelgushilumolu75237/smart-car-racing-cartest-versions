# 视觉入口版：上方入口再入环

本目录为2026-11-12独立实验工作区。配套相机程序与H743固件必须来自同一版本。原工程及配套ELF已保留在任务根目录的baseline和paired-elf-baseline中。

仅入环和绕环：轮速降至原档75%，舵机相对1530μs的偏转量增至130%，保留1100～2500μs限幅。普通直道、普通弯道、回中和出环阶段沿用原控制。上方入口未获可靠许可时保持普通循迹，跳过环岛，不伪造有效路线。

入口参数尚需停车手推实测，不随软件包提供假定标定值。使用方法见[两套入口版本与手推标定](docs/RingEntry_TwoVersions_20261112.md)。软件验证与交叉构建不代表车辆已经通过赛道。

# OpenMV r24 陀螺仪与逐飞无线移植版（2026-11-12）

当前 `openmv/` 为完整生产视觉包，共 25 个运行 Python 模块。
保留原 r24 的识线、普通弯道、单边补线、环岛识别条件和上电宽度自动标定。
`config.BUILD_ID` 保留原视觉算法标识；本次扩展版本以配套清单、源文件哈希及 Git 标签识别。

新增 V4 环岛事件、H743 陀螺仪接管及数值/命令侧带；不含图传或新的电脑上位机。
串口保持 OpenMV UART3、115200、8N1；不要混用 K230 程序、2M 配置或旧 V3 相机包。
必须同时更新本包全部运行 `.py` 与配套 H743 ELF；保留当前厂商底层固件和本机宽度标定。
`validation/mpy` 仅作交叉编译证据，不作为安装文件。

六个 Debug 档位为 A、B、C、C+20%、C+30%、C+40%；它们共用同一相机包。
原程序确认环岛后立即交给陀螺仪入环，视觉确认入环结束后累计净转角 350°，
回中后保持 300ms，再按约定恢复普通循迹或进入有期限的直行寻线。
具体速度、接线、逐飞命令、参数保存与安装说明见
`docs/OpenMV_R24_GyroWireless_20261112.md` 和 `tests/wireless/PROTOCOL.md`。

本次只进行软件测试、交叉构建和打包；没有上传相机、烧录或复位 H743、启动电机。
实机通信、帧率、绕环参数和赛道效果尚未验收。
