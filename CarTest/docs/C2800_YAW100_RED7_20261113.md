# C原速环岛2.8圈/秒、100°/秒与红障7%版

按用户确认，将“目标加速度100”落实为目标车身角速度100°/秒，不新增加速度控制参数。

| 参数 | 当前值 |
|---|---|
| C原速入环、绕环外轮速度目标 | 2.800圈/秒 |
| C原速环岛车身角速度目标 | 左右镜像±100°/秒 |
| 红色触发 | 320×120全幅实际红色像素严格大于2688，即超过7%；2688不触发，2689起触发 |
| 框色 | 总红色像素≤2688蓝框，>2688绿框 |

识别后回中直行保持1100ms，沿用与入环共用的轮速目标，因此C原速这段直行目标也为2.800圈/秒。确认入环后累计净转角340°出环、出环回中300ms、原出环5.280圈/秒、舵机1875‰偏转系数及1100～2500μs限位均不变。

绕障路线仍为1→2→3→5→6→7，跳过第4段；左前斜行1圈、右前斜行1.5圈，转弯角度和普通直道/弯道速度保持上版。红色事件只发一次R，视觉尺寸320×120、显示640×480保持。该路线仍为待实车调参的候选值。

仅C原速的环岛轮速及角速度按本次修改；B和C+20%/+30%/+40%档的环岛目标保持上版。A仍不执行环岛。无线轮速缩放仍影响实际轮速目标。

## 安装

H743：人工烧录当前工作区Debug C Base档位，或本包H743/C_RingFast/CarTest.elf。其余五档也提供配套ELF，保持各档既定参数。

K230：若已装上一版320×120，只需更新K230_RED/red_detector.py；完整安装仍用main.py、settings.py、red_detector.py放入/sdcard/cartest-k230/。startup.py为根目录启动器源文件，正常启动时不需修改。更新后人工重新上电。

OpenMV：本次未改源码。接线、通信、保护、红障优先级未改变。

## 验证

验证覆盖2688/2689严格边界、蓝绿框、UART/LCD初始化、六档状态机、C原速目标2800毫圈/秒与100000毫度/秒、原OpenMV/无线回归及ARM构建。详见validation/software-validation.json。本次未自动上传相机、烧录或复位H743、启动电机；尚未验证新参数的实车表现。
