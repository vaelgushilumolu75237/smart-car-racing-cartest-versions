# 当前入口修正版

本目录已派生为独立入口版本，入口门控、手推标定和第4页诊断以 [两套入口说明](RingEntry_TwoVersions_20261112.md) 为准。以下保留原无线与陀螺仪接线、参数和启动说明。

# OpenMV r24 陀螺仪与逐飞无线移植版

基线已发布为 GitHub 标签 `刚换回openmv`，提交 `57b8668ab917124f691e4c7b977446ff16491b4c`。
本版从该基线派生，保留 OpenMV 原识线、普通弯道、单边补线及上电宽度自动标定。
不移植 K230 图像算法，不提供图传，不新增电脑上位机。

## 安装与版本配对

本版需要同时更新 OpenMV Python 程序及 H743 固件。
保留 OpenMV 当前厂商底层固件；将交付包 `OpenMV` 目录中的全部运行 `.py` 文件一起复制到相机运行目录。
`validation/mpy` 仅用于交叉编译验证，不上传相机。保留实车已有的宽度标定文件。
H743 在当前工程 Debug 六个入口中任选一个，或者手动烧录交付包对应 `H743/<档位>/CarTest.elf`。
六档共用同一套相机程序，由主控握手选择 A/B/C。
旧版 V3 相机程序不能用于 B/C 陀螺仪控制档；只有新 V4 包含环岛阶段及方向。
本次软件交付没有执行相机上传、H743 烧录、复位或电机启动。

## 速度和环岛控制

| 档位 | 直道轮速目标 rps | 普通弯道外轮目标 rps | 环内外轮目标 rps | 环内角速度初值 °/s |
| --- | ---: | ---: | ---: | ---: |
| 新 A | 5.600 | 4.400 | 不启用环岛 | 不启用 |
| B | 4.800 | 4.000 | 3.000 | 64.935 |
| C 原速 | 5.600 | 4.400 | 3.960 | 85.714 |
| C +20% | 6.720 | 5.280 | 4.752 | 102.857 |
| C +30% | 7.280 | 5.720 | 5.148 | 111.429 |
| C +40% | 7.840 | 6.160 | 5.544 | 120.000 |

角速度为按原 +40% 档比例得到的候选初值，左右方向符号镜像，仍需实车调节。
这些数值为轮速和角速度控制目标，不是实测车速或赛道通过结果。

1. 原r24识别条件只提供环岛候选；首次稳定识别后前进至手推标定的平均轮转行程后，才允许入环。缺失标定或入口不可靠时普通循迹并跳过环岛。
2. 陀螺仪闭环入环。原相机入环过渡结束后，连续三帧确认同侧环内状态，才清零绕环累计角。
3. 环内由陀螺仪独立闭环控制，临时看不到边界不会直接退出环岛控制。累计沿本次绕环方向的净转角，来回摆动不取绝对值相加。
4. 达到 350°立即回中；软件实际输出 PWM 到达 1530μs 后直行保持 300ms。
5. 固定出环动作结束后，连续三帧新鲜普通路线可交还循迹；否则保持回中，用独立 300ms 减速过程最多续行 3 秒，超时停车等待路线恢复。无效帧不得延长截止时间。
6. 普通道路沿用原丢线规则：A/B 为 2秒/200ms，C 为 3秒/300ms；与陀螺仪出环专用 3秒/300ms 分开。

保留 PE7 停止、故障锁存、相机通信故障停车、IMU 异常停车，以及入环 4秒、绕环 16秒、回中 1秒的阶段上限。
A 档不启用环岛，也不要求 IMU 校准通过才能循迹；仍可查看 IMU 诊断。
B/C 上电需静止约 2 秒完成 IMU 零偏校准，晃动会重新等待，未通过不能启动。

## 串口和接线

OpenMV 原 UART3 与 H743 USART1 继续使用 115200、8N1，保留原有接线并共地。
不使用 K230 GPIO9/10，也不切换到 K230 的 2M 波特率。

| ICM42688 信号 | H743 |
| --- | --- |
| CS | PB12 |
| SCK | PB13 |
| SDO / MISO | PB14 |
| SDI / MOSI | PB15 |
| GND | GND |

模块平放，Z轴垂直地面。沿用当前模块供电及已验证的 SPI 接线。
驱动沿用 T2 已修复的 GPIO 模拟 SPI mode 0 实现，保留有界事务和超时诊断。

| 无线模块信号 | H743 |
| --- | --- |
| RX | PA2 / USART2 TX |
| TX | PA3 / USART2 RX |
| GND | GND |
| RTS（原已接时） | PA4，上拉输入 |
| CMD（原已接时） | PA5，上拉输入 |

无线串口初始 115200、8N1，无硬件流控。软件不主动驱动 RTS/CMD 拉低。
无线失联时继续本地循迹，不要求电脑保活；重连不自动重放旧的启动指令。

## 参数保存和边界

只使用现有逐飞助手。无线配置软件用于配置模块，车辆数据使用逐飞助手的示波器及串口终端。
实时数值目标 20Hz；实际无线吞吐和实车帧率需硬件测量。
启动仍检查原有按键释放、视觉/握手、编码器、通信及故障条件；无线不能解除 PE7 停止和故障锁存。

行驶时只允许有限调参：轮速缩放为本档默认 25%～100%，角速度 30～180°/s，循迹 PD、轮速 PI、陀螺仪 PI 为默认增益的 50%～150%。
350°门限、时长、舵机及编码器配置等只允许停车修改。
相机 PD 必须收到相机真实回执后才报告已采用；超时或拒绝不能假称成功。
先临时修改 RAM，停车后显式保存。六档参数按 profile 和 speed 分开保存，宽度标定供同一安装位置共用。
H743 使用 Bank2 最后两个扇区的双槽 CRC 配置区，链接器预留该区域，固件代码限制在前 1792KiB。
两端保存、恢复默认的结果分别回传，不假称跨设备事务同时成功。

逐飞助手的具体命令和页面映射见交付包 `WIRELESS_PROTOCOL.md`（工程内为 `tests/wireless/PROTOCOL.md`）。

## 逐飞助手操作

串口选择无线 USB 实际 COM 号，115200、8N1，不启用硬件流控。
数值使用示波器；文本命令在同一个逐飞助手的串口终端发送，末尾加换行。
先发送 `ARM`，查看第5页第3通道的七位票据，再在30秒内发送 `START 七位票据`。
`ARM` 不驱动车辆，`START` 仍需通过全部原启动条件；票据使用一次后失效。
停止发送 `STOP`，本地 PE7 仍可停止。

页面由调参第8通道选择，填写0～5的整数。调参第1～7通道随页面变化；
界面通道序号从1开始，协议内部索引从0开始。

| 页面值 | 示波器内容 | 调参第1～7通道 |
| --- | --- | --- |
| 0 | 毫秒、模式、故障、故障锁存、会话、驱动许可、路线有效、序号、视觉误差、置信度、左右实测轮速、左右目标轮速、舵机、左电机 | 轮速缩放、角速度、视觉P、视觉D、轮速P、轮速I、陀螺仪P |
| 1 | 视觉误差、置信度、左右实测轮速、左右目标轮速、舵机、左右电机、IMU就绪、IMU故障、Z角速度、累计角、环岛阶段、环岛净转角、环岛故障 | 陀螺仪I、绕环角门限、回中直行时间、寻线时间、左舵端点、右舵端点、左编码器CPR |
| 2 | 右电机、IMU就绪、IMU故障、Z角速度、累计角、环岛阶段、环岛净转角、环岛故障、相机通信龄期、相机帧数、配置代数、接收溢出、无线丢包、相机丢包、当前页、毫秒 | 右编码器CPR、左编码器方向、右编码器方向；余下不用 |

| 4 | 相机FPS、有效、环岛状态、弯道阶段、档位、会话、处理ms、已接受P/D、相机回执/操作/详情、路线源、方向、偏差、控制量 | 不调参 |

轮速为 milli-rps，角速度为 milli-degrees/s，角度为 milli-degrees，
增益及速度缩放为千分比（1000表示默认100%），舵机为微秒，时间为毫秒。
`READ` 查询H743，`READCAM` 查询相机；`DEFAULT` 恢复本档RAM默认，
并通过正常回执流程同步相机默认PD。
`SAVE` 停车显式保存H743，`SAVECAM` 独立保存相机已确认采用的PD，
两端结果分别报告；尚未同步时相机保存会被拒绝。
这些查询/保存命令需先 `ARM` 建立会话，`ARM` 本身不会启动。
`IMUCAL` 停车重新校准陀螺仪；`CALWIDTH` 停车触发原相机宽度标定。
命令结果以实际回执为准。
相机接受的PD值通过READCAM及相机真实CONFIG/ACK返回，H743期望值和相机实际采用值可能因通信超时暂时不同。

## 验证范围

软件验证包括原有控制回归、环岛方向与净转角、IMU 校准及异常、入出环超时、恢复路线、无线权限/重放/限幅/保存、OpenMV 运行模块交叉编译及六档 H743 实际交叉构建。
完整检查结果以交付包 `validation/software-validation.json` 为准。
编译及主机测试通过不代表已在相机和车辆上运行，也不证明帧率或赛道表现。
