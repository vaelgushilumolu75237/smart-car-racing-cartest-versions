# 320×120 USB预览与FIFO发送验证（2026-10-25）

本轮只优化串口发送与USB预览链路，没有调整路线选择、位置权重、PD、预瞄或H743转向参数。下面是相机静止对准直道时的结果，不能替代连续弯道和实车验收。

识线使用未压缩的320×120灰度图；USB预览使用相同分辨率的JPEG，质量参数为10。帧率提升没有通过缩小图像或重复发送旧路线实现，预览压缩质量与识线输入应分开理解。

所有上述板端完整窗口中，相机算法计算出的路线均有效。为保持车辆不运行，测试发送器只向物理UART发送固定序号0、路线无效、控制字段全零的16字节V2帧；算法生成的真实控制包没有转发给核心板。反向RESET/KEEP由测试替身提供。因此，这些结果验证计算与传输的时间预算，不证明有效路线的电控执行或整车行为。

FIFO包装层65秒SDK测试共接受3944个发送包，未出现忙碌、短写或异常，测试前后TC均为true。主机解码得到3941个新序号，漏3个序号，无重复、倒序或标记CRC错误；这一轮期间另有一次并发SWD读取。H743的独立一秒快照解析到60个无效测试帧，序号检查拒绝60个固定序号，解析错误为0，启动令牌、启动事件和执行器输出均为0。

实际IDE测试共接受3949个FIFO发送包，忙碌、短写和异常均为0，TC测试前后为true。IDE日志中的3986组声明长度与完整读取长度均匹配；该总数包含启动或运行结束附近的读取，不能当作3986个唯一新帧。IDE速率来自完整payload读取日志，不是独立逐帧JPEG解码、序号标记核验或物理屏幕刷新计数。SDK独立解码数据与IDE读取数据分别报告。

关闭CDC会话的FIFO测试已完整回收六个窗口：79.4、79.4、79.2、79.4、79.2、79.3帧/秒；各窗口计算路线全部有效。65秒共接受5156个FIFO包，无忙碌、短写或异常，TC前后均为true，JPEG标记写入为0，预览状态为`NATIVE_HEADLESS`。各完整窗口总周期的P95上界为13000微秒，最大周期最高为30759微秒。关闭CDC的时间为68秒，USB线保持连接，不能把它当作物理拔线测量。一次独立H743快照还解析到79个无效帧/秒；有效路线控制仍未验证。

测试脚本最初一次性输出报告，超出了固件1024字节终端环的1023字节有效容量，前部记录丢失。失败记录保留；成功结果来自修改为测量结束后逐行回传的独立补测，未用残缺报告计算达标。生产运行文件不受这一测试脚本修复影响。
