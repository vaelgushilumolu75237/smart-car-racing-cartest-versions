# OpenMV 静态预览验证记录 — 2026-10-24

## 验证范围

本记录支持静态视觉预览软件里程碑。它不证明 H743 接收 UART 帧、整车闭环达到 60 FPS，也不证明道路或车辆验收通过。文中只保留测量摘要；没有附加帧图像、设备标识或原始会话日志。

## 板端与预览测量

- 分辨率配置为 320×120，预览尺寸观察结果也为 320×120。
- 19 个运行模块从隔离相机文件系统加载；小型性能 runner 由 RAM 注入。
- IDE 收到 3693 个完整 JPEG payload。3693 个 payload 大小均与预期匹配，读取错误为 0。
- 五个完整 payload 读取窗口分别测得 60.4380、60.3276、60.2762、60.3608、60.289 次/秒。这些数据表示完整 payload 被读取的速率。
- 本次未独立记录 IDE 逐帧解码成功和尺寸。固件解锁会清空缓冲区，避免重复读取同一已发布缓冲；但本次 IDE 测量未逐帧解码序号 marker，因此没有独立逐帧新鲜性校验。
- 主机 SDK 另行解码帧内序号 marker，得到 60.4–60.5 个新序号/秒。这是独立于 IDE payload 读取速率的主机测量。
- IDE GUI 先将平均帧间隔截断为整数毫秒，再以 1000 除以该值计算帧率，显示值可能偏高，不作为精确帧率证据。

## CDC 关闭时的 headless 测试

持续 60 秒的测试中，USB 状态始终为 `NATIVE_HEADLESS`，没有 JPEG marker 写入。六个 10 秒窗口的有效路由计数为 796、796、797、795、797、795，共 4777 条，窗口速率为 79.5–79.7 条/秒。此项测试没有打开 USB 预览，不能代表预览吞吐量。

## UART 时间近似

另一次 20 秒实验在每帧写入路径注入 `pyb.udelay(1389)` 微秒，测得 55.6–55.7 次/秒。该延迟用于近似 115200 波特率下 16 字节的 wire time；它没有通过 UART 发送数据，不是实际 UART 吞吐测量，也不是 H743 接收测试。

## 软件验证

- OpenMV 主机回归：242 项运行，239 项通过，3 项跳过，0 项失败。
- OpenMV USB 预览工具主机测试：44 项通过。
- 19 个运行模块均通过 `mpy-cross -march=armv7emsp` 编译，退出码为 0。

## 配对和安全边界

当前 H743 `C Incremental PI 20261020` 核心保持不变，未烧录或复位 H743；电机未启动。相机测试使用无操作 UART sink，不代表 H743 接收。V2 UART 帧的实际 H743 接收、完整 UART 闭环、整车 60 FPS、道路测试均未通过验收。本文不包含或声称新的 UART FIFO API 已构建、安装或运行。
