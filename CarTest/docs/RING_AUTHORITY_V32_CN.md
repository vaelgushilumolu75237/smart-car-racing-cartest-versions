# V32：环岛弧线确认后才授权陀螺仪入环

V31相机在STATE_ENTER时直接发送V4入环请求。但该状态只表示连续单边缺失，尚未通过后续环岛弧线确认；普通弯道丢边可能因此过早启动H743的陀螺仪入环动作。

本版修正gyro_link.py的授权条件。STATE_ENTRY_CONFIRM、STATE_ENTER均不请求陀螺仪接管，通过原验证的普通路线和左右单边补线继续携带ordinary资格。只有STATE_INSIDE、ring_confirmed、target_valid、有效当前视觉包、标定和新鲜会话均满足，且确认路径为GROWING_ARC或PEAK_REVERSAL时，才首次发出ENTRY。这里的STATE_INSIDE是视觉识别器的弧线确认状态，不直接等同于主控已完成入环。

授权后保持左右方向绑定。视觉入环过渡结束，再有连续三帧当前同方向有效环内证据，才发送INSIDE，供主控清零并开始累计350度。不得先发INSIDE再补ENTRY。重复、倒退、过期帧不能首次授权；无效帧、预算不足、未标定、旧会话均不能授权。350度退出释放、故障停车和PE7保护保留。

新增测试调用真实跟踪器的丢边确认方法：确实进入STATE_ENTER，但环岛尚未确认；左右弯道补线路线必须始终发送phase=0、ordinary=1。相同测试在V31会发送phase=1而失败，修复后通过。额外覆盖未确认弧线、无目标、无效帧以及重复和倒退序列。已有左右环岛ENTRY→三帧INSIDE、退出释放和普通单边主循环回归继续执行。

这是相机授权修正，主控源码和20套配套ELF不变，无需因本次修正重复烧录H743。单独更新相机不能解除主控已经锁存的17号故障，实测前仍需按原有停止/故障确认流程处理，不能无线绕过保护。

安装时只需要替换/sdcard/cartest-k230/gyro_link.py和PACKAGE_MANIFEST.json；完整相机包也提供33个匹配源文件。保留开机入口、标定和用户参数。相机正式文件尚未自动安装，H743未烧录/复位，电机未启动。V31的65帧实测是历史结果，本版尚未重新测帧率或验证真实赛道，不宣称已消除所有普通弯道误判，也不把17号故障码单独作为本次误入环的实车证明。
