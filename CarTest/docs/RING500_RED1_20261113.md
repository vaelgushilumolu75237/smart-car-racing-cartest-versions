# 环岛500ms与红障1%参数版

基于上一版环岛500ms、蓝绿框版本，仅把K230全幅320×240红色触发门限改为严格大于1%，即红色实际像素超过768才触发，等于768不触发。所有红色连通区域合计计数；连续事件只发一次R。画框颜色共用同一门限：≤768蓝色，>768绿色。画框不改变原始检测图像。

环岛与固定绕行参数均不变：识别环岛后回中直行500ms，入环/绕环速度为原环岛基准的37.5%（C原速1.980圈/秒），舵机相对中位偏转系数1875‰，保留1100～2500μs限位；绕障第4段左右轮平均前进1圈。350°门限、出环300ms、其余绕行段及普通速度不变。

K230：将K230_RED/main.py、settings.py、red_detector.py放入/sdcard/cartest-k230/。已在用上一版时，仅替换red_detector.py即可。startup.py为根目录启动器源文件，现有正常启动入口不需修改。识别分辨率320×240、屏幕显示640×480。

H743六档ELF与上一版完全一致，本次无需重新烧录。OpenMV源码也未改。本版没有自动写入相机、烧录/复位主控或启动电机。

验证覆盖768/769严格边界、事件重入、框颜色及LCD/UART初始化；软件通过不表示已在相机实机或赛道验证。详细证据见validation/software-validation.json。
