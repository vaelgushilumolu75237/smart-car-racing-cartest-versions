# K230 / H743 无线诊断与控制版

本版基于已发布的 Gyro350 版本，使用独立工作区。配套固件配置为 `DebugWirelessGyro350Speed140`；相机安装生产 `openmv` 目录中的全部运行文件。旧配置用于恢复，不是新增无线功能的配套固件。

## 接线与模块配置

| H743 / 电源 | 逐飞无线转串口模块 | 说明 |
| --- | --- | --- |
| PA2 / USART2_TX | RX | 交叉连接，3.3V UART 电平 |
| PA3 / USART2_RX | TX | 交叉连接，3.3V UART 电平 |
| 稳定 5V | 5V | 按用户提供的模块说明书供电 |
| GND | GND | H743、相机和无线模块共地 |
| 3.3V 经 10kΩ | RTS | 本版不使用流控，按说明书上拉 |
| 正常通信高电平 | CMD | 低电平进入配置；信号电平为 0～3.3V |

PA2、PA3 是固件采用的 MCU 引脚，主板排针位置仍需对照实际板卡确认。K230 与 H743 原有专用串口接线保持原方案，不能与无线模块并接到同一收发线上。

亚博 K230 豪华版整板使用 **5V 供电**，可使用板上 Type-C 或对应 5V 电源接口；电源电压与 UART 的 3.3V 逻辑电平是两个概念。官方资料来源：`https://www.yahboom.net/study/K230/15198`。

用“逐飞科技无线转串口上位机”配置模块：初始 UART 为 115200、8N1，两端无线参数匹配，CMD 恢复通信状态。建议选择达到重发次数后丢弃，避免旧遥测持续堆积。此次软件工作未连接或修改真实模块。

## 电脑使用

完整工具在项目根目录运行：

```powershell
python -m tools.wireless.complete_tool
```

需要 Python、Tkinter；实际连接串口时需安装 `pyserial`。工具启动不会自动连接或启动车辆。选择 COM，点击连接、HELLO 握手，切换完整工具模式后使用操作按钮。状态、曲线、图像及命令回执在工具中显示；日志保存至用户选择的本地目录。

逐飞助手与完整工具轮流占用 COM。默认发送逐飞助手兼容数据；通过完整工具切换回助手模式后关闭其串口，再打开逐飞助手。助手提供最多 16 个曲线通道；调参通道 7（从 0 开始）选择页 0～2，其余通道映射见协议说明。启停、保存、校准和执行器测试使用完整工具。

目标发送率为数值 20Hz、详细诊断 2Hz、80×60 二值图 2fps。相机处理能力、串口队列和实际无线吞吐会降低图像帧率；控制和数值优先。320×240 灰度图只在停车时按需分片慢传，整图重组最长等待 60 秒；丢片会丢弃该图，需重新抓取。软件测试不证明实车吞吐或图像帧率。

## 控制和参数

- 无线启动沿用原启动门控：按键上电释放、IMU 校准、视觉通信与普通路线、编码器及故障条件。无线断连不停止正常本地循迹；测试动作仍到时停止。
- 行驶可调：轮速缩放为原各阶段目标的 25%～100%；绕环角速度 30～180°/s；循迹 PD、轮速 PI 和角速度 PI 增益为默认值的 50%～150%。
- 环岛累计角、出环/续行时长、舵机端点与编码器参数只停车修改。舵机中位固定 1530μs，不能通过调参解除原保护。
- 修改先在 RAM 生效，停车后显式保存。H743 使用预留 Flash 双槽与校验；K230 使用独立配置文件。两端分别回执，某一端成功不表示另一端已保存。
- 默认环岛方案仍为相机确认入环后累计净转角 350°，绕环目标 ±120°/s、外轮 7.392 转/秒；回中后 300ms，再按约定最多续行 3 秒。候选参数需要实车调试。
- 停车电机测试仅向前，左/右/双轮，占空比最大 40%、单次最长 5 秒；舵机 1100～2500μs、单次最长 1 秒后回中。重复请求不延长动作，本地停止和故障优先。
- IMU 校准指令回执表示已接受校准请求；是否完成以 IMU ready/fault 状态为准。K230 宽度标定回传进度及最终结果。

完整协议使用会话、递增请求编号、时间戳及 CRC，拒绝旧会话、过期命令和重复执行。逐飞助手原生调参协议没有会话或时间戳，只开放有范围限制的参数操作，不能承担完整工具的启停或执行器命令。

完整工具中的 `SET group/id/value` 使用以下整数单位。读取配置可查看当前实际值。

| group | id | 参数 / 单位 |
| --- | --- | --- |
| 1 | 1 | 轮速缩放，千分比 250～1000 |
| 1 | 3 / 17 | 视觉 P / D 缩放，千分比 500～1500 |
| 1 | 4 / 5 | 轮速 P / I 缩放，千分比 500～1500 |
| 2 | 2 | 绕环角速度，毫度/秒 30000～180000 |
| 2 | 6 / 7 | 角速度 P / I 缩放，千分比 500～1500 |
| 3 | 8 | 绕环累计角，毫度，默认 350000 |
| 3 | 9 / 10 | 回中直行 / 后续搜线时限，毫秒，默认 300 / 3000 |
| 4 | 11 / 12 | 左 / 右舵机端点，微秒，默认 1100 / 2500 |
| 4 | 13 / 14 | 左 / 右编码器每转计数 |
| 4 | 15 / 16 | 左 / 右编码器方向，+1 或 -1 |

逐飞助手的调参通道按从 0 开始编号：通道 7 选择页；页 0 的通道 0～6 对应参数 id `1,2,3,17,4,5,6`；页 1 对应 `7,8,9,10,11,12,13`；页 2 的通道 0～2 对应 `14,15,16`，其余忽略。输入单位与上表相同。完整工具操作优先使用参数回读及回执确认。

## 验证与恢复

本次仅做源码、主机测试、相机字节码编译和 H743 交叉构建。没有烧录、复位 H743、上传相机或启动电机。实物引脚、IMU 安装方向、串口质量、转向效果和赛道通过情况仍需硬件验证。

修改前源码、配置、配套 ELF 与哈希保存在工作区上一级 `private-baseline`；旧 Gyro350 工程未覆盖。公开检查点不包含真实车辆日志、用户图片或实车标定。
