# V31 相机65帧交付

最终源码在K230内存中连续运行45秒。自动标定结束后，连续三个完整10秒窗口分别获得653、651、652张新图，全部通过有效路线校验并完成串口发送：65.3、65.1、65.2帧/秒，平均65.2帧/秒。串口写入错误和超时无效帧均为0。启动窗口包含密集标定，不用于稳定帧率结论；本次完成64帧自动标定和停车核验用时约1.76秒，实际时间随画面条件变化。

测试使用真实摄像头、真实识线和真实GPIO9/10 UART1发送，输入的H743状态由内存测试夹具模拟。尚未验证H743实际接收帧率，也未验证行驶中的弯道和环岛。该结果不保证每种画面、标定阶段或复杂分支都持续65帧。

处理分辨率继续为320×120完整中央裁剪，按精确4×2最小值汇聚为80×60，保留每帧新图、全图拓扑、边界证据、单边补线、环岛密集基准、显示与无线诊断。优化原生数组运算、路径搜索中不可能入选的分支及诊断数据打包。详细阶段耗时均匀每8帧采样一次；新图数量、有效帧、串口完成/失败和整帧总耗时仍逐帧记录，并在日志明确标注采样间隔。

额外修复CanMV ulab二值图缓冲区所有权：原生tobytes返回别名时，立即复制为独立不可变数据，避免后续原生调用或回收改变已完成的分块。160组板上原生差分测试覆盖整行与局部矩形、常量、阈值平局，输出与原阈值算术一致。

主控沿用V30配套ELF，普通直道5.6转/秒、弯道外轮4.4转/秒、环岛外轮7.392转/秒；本次不用重新烧录H743。候选摄像头源文件已回归验证并交叉编译33个模块。旧源码、配置和20套配套ELF及SHA256保存在私有before-fps65备份中。

安装目录的K230子目录为完整相机运行文件。安装到/sdcard/cartest-k230时，替换该目录中的33个.py文件及PACKAGE_MANIFEST.json；保留原boot.py、标定文件和用户参数。安装包中的ring_width_calibration.json为明确未就绪的占位文件，不覆盖实车标定。自动标定保留开启。相机安装需要单独授权或用户手动完成；当前尚未写入正式相机文件，没有烧录/复位H743或启动电机。
