# V29：恢复环岛入口所需的连续行基准

## 已复现的回归

原T2环岛入口要求至少4行连续的单侧缺失/外扩证据，同时保留对侧
近场锚点。后续K230提速使用隔行路径采样；单边宽度缓存可能在一帧
建立，而环岛自己的稳定基准需要连续3帧。原运行链只在宽度缓存为空时
强制完整行，因此环岛最终可能冻结仅21行的隔行基准。

入口扫描在基准无测量的行中断连续段。相同合成输入的主机重放显示：
完整52行基准可进入ENTRY_CONFIRM→ENTER；同样输入配合隔行基准时，
连续段最长仅1～2行，停在OBSERVE。本结论为代码回归重放，不冒称
已经读取本次用户驶过环岛时的现场诊断。

## 修正

在新鲜控制和有效的B/C运行会话中，环岛基准尚未建立时继续使用
完整行，直到原稳定条件通过。基准建立后恢复原隔行采样。
不插值缺失行、不降低连续性门槛、不复用旧帧作为新测量。
原拓扑、标定、普通弯道排除、CRC及陀螺仪350°控制继续执行。
