# r24 OpenMV上电自动宽度标定

版本 v20261112-openmv-r24-auto-calibration，基于 b0853010652887426ad9a8509b62029394c2758f。
只修改生产openmv视觉包；H743控制和所有配套ELF保持原版，不用重新烧录主控。

缺失或无效宽度图时，等待主控B/C停车状态，至少3条不同序号且档位、会话和轮位一致的新鲜状态；传感器身份正确、双边路线通过原边界验证、拓扑清楚且无环岛/分岔，才自动收集64个合格帧。状态中断或身份/轮位改变丢弃部分样本。最初合格帧起60秒超时，本次上电停止尝试，不能自动启动。

收集成功后使用原CRC格式保存ring_width_calibration.json，重新加载校验，通过后仍须原3帧停车宽度复核。已有有效标定不自动覆盖。保存/读回失败不开放启动门控。保持原320x120图像、r24环岛算法、通信、速度、PE7和丢线规则。

车辆放在45cm直道中央，保持停止，左右边界尤其画面近处均可见；连接主控相机通信并共地，再由用户上电。时间取决于合格帧率：采集约64/FPS秒，另加初始化、停车确认和3帧复核；通常可预留数秒，未实机测量，场景不合格不会按时间强行通过。主控如处在等待启动边沿，标定通过后仍按原PE7逻辑操作。

验证：537项OpenMV主机测试通过（4项跳过），含8项新增自动标定测试；23模块armv7emsp交叉编译。修正了旧测试遗留r23版本字符串，算法冻结检查只增加自动标定配置白名单。H743既有ELF复用，不是新构建。未运行相机、未复位或烧录H743、未启动电机，未宣称实车已通过。
