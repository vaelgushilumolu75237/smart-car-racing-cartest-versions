# 无线环岛角速度使用源码配置

此前环岛在无线开启时读取运行设置，旧C档无线默认角速度85.714°/秒覆盖了gyro350_config.h的配置；旧无线范围上限180°/秒又无法接受极限2的260°/秒。

本版修复：

- 当前C档无线默认角速度直接使用CAR_GYRO350_TARGET_YAW_RATE_MDPS，它由gyro350_config.h各档CARTEST_RING_RATE_MDPS选择。
- 上电加载有效Flash参数后，只把角速度重新设为本版源码值，避免旧保存值再次覆盖；不擦写Flash，其他有效保存参数保持。
- 无线角速度调参范围上限为max(180°/秒,本档源码角速度)，下限仍30°/秒。极限2当前为30～260°/秒；范围校验及持久化记录验证保持有效。
- 无线修改角速度仍在当前运行期间生效；即使停车保存，重新上电也以源码角速度为准。这是明确的启动优先级；不再使用旧保存角速度作为启动目标。

当前三档角速度为100、145、260°/秒。极限测试档2其余参数保持：直道和入环/绕环6.2圈/秒、普通弯道外轮4.4圈/秒、识别后回中直行700ms；原环岛、绕障、黑标停车和故障保护不改。

修改文件：App/wireless_settings.c、App/wireless_runtime.c及配套元数据、Debug显示和测试。用户已修改的Inc/gyro350_config.h中260000予以保留。

回归实际链接wireless_runtime、wireless_settings和gyro_ring，覆盖空Flash与旧85.714保存值、其他保存参数保留、左右环岛闭环输出、前置直行到期、调参边界和设置记录编码读回；另通过三档轮速PI/环岛/IMU/控制权限/绕障回归和实际ARM构建。

手动烧录H743/C_Limit2/CarTest.elf或DebugRingFastLimit2，重启后可通过ST-Link只读engine.settings.gyro_rate_mdps确认260000。相机无需更新；本地包仍含既有标定文件。本次未烧录、复位或启动车辆，未实测实车效果，未处理此前独立的视觉串口错误。本次不上传GitHub。
