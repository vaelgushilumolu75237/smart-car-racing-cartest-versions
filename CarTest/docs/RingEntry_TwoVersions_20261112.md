# 环岛入口修正版：视觉版与编码器版

两个版本分别测试，使用各自目录里的OpenMV程序和H743固件，不混装。原工程未覆盖。当前为软件验证版本，入口标定和实车效果仍待验证。

## 两套运行逻辑

视觉版：原识别器发现环岛后只作准备；当前画面连续符合手推标定的上方入口位置，才允许环岛路线与陀螺仪接管。首次识别位置、下方开口作为排除样本保存，不能与上方入口的接受窗口重叠。

编码器版：原识别器首次稳定确认环岛时记录轮转量起点；沿普通路线前进至手推标定的入口行程，再允许入环。标定量为左右轮前进转数的平均值，不是米；不依靠猜测轮径换算。该版本运行时不使用视觉版入口窗口作为第二道距离门槛。

入口不可靠或错过入口等待期限时，沿普通路线跳过本次环岛。普通路线必须有真实的当帧证据；没有路线时仍按原丢线规则处理，不发送伪造的零偏差有效帧。

两套都支持左右环岛。入环完成由入环许可后的新鲜相机证据确认，随后清零并累计本方向净转角350°，不把来回摆动的绝对角度相加。之后回中，软件输出到1530μs后保持300ms；再交还普通循迹。无普通路线时沿原300ms减速过程，最多继续3秒，期限不被无效帧延长。保留PE7、通信故障、IMU故障与各阶段超时保护。

## 速度与舵机

只有ENTRY入环、ORBIT绕环阶段降低25%轮速并增加30%舵量。普通直道、普通弯道、CENTER回中和EXIT出环保留原配置；角速度目标保持本档原值。

| 档位 | 入环/绕环外轮目标（转/秒） | 回中/出环外轮基准（转/秒） | 环岛角速度候选（度/秒） |
| --- | --- | --- | --- |
| A 快速无环岛 | 不启用环岛 | 不适用 | 不启用 |
| B 环岛基础 | 3.000 | 4.000 | 64.935 |
| C 原速 | 3.960 | 5.280 | 85.714 |
| C +20% | 4.752 | 6.336 | 102.857 |
| C +30% | 5.148 | 6.864 | 111.429 |
| C +40% | 5.544 | 7.392 | 120.000 |

舵量增加指相对1530μs中位的PWM偏差乘1.30，最终仍限幅1100～2500μs。它不等于机械前轮角度增加30%，也不能保证实车转弯半径恰好缩小到赛道要求。

## 安装和恢复

打开选定版本的 `CarTest.code-workspace`。Debug名称前缀分别是“视觉入口版”和“编码器入口版”，并标有该档入环绕环轮速。

相机文件使用交付目录 `OpenMV` 中的全部运行 `.py` 文件；保留原赛道宽度标定及现有相机固件。配套H743 ELF在 `H743/<档位>/CarTest.elf`。交付目录的 `validation/mpy` 是交叉编译证据，不是上传目录。两套版本识线分辨率保持320×120，不增加无线图传或电脑软件。

原版在任务根目录的 `baseline/CarTest` 与 `paired-elf-baseline`，哈希和恢复步骤见 `RESTORE.md`。本次没有自动上传、烧录、复位或启动电机。

## 手推前准备

使用现有逐飞助手及原无线模块，115200、8N1；不新开另一个程序占用COM。文本命令末尾加换行。先停车，确认电机关闭、故障已按原规则解除。宽度自动标定需要先在清晰的双边直道完成，IMU需静止校准。

标记时只手推，不发START。三个位置按顺序为：首次稳定识别环岛、下方开口经过、前轮到达正确上方入口打舵点。照片蓝线路径为右环岛，方向编号1；镜像左环岛编号0。三个位置记录本地灰度图、入口几何和轮转量，图片不通过无线发送。

三标记命令在视觉版用 `VCAL` 前缀，在编码器版用 `ECAL` 前缀。右环岛流程分别为：

| 动作 | 视觉版命令 | 编码器版命令 |
| --- | --- | --- |
| 建立停车命令会话 | `ARM` | `ARM` |
| 开始新一轮采集、重置手推里程 | `VCALRESET` | `ECALRESET` |
| 首次稳定识别位置 | `VCALMARK10` | `ECALMARK10` |
| 下方开口经过位置 | `VCALMARK11` | `ECALMARK11` |
| 正确上方入口打舵位置 | `VCALMARK12` | `ECALMARK12` |
| 提交该方向 | `VCALCOMMIT1` | `ECALCOMMIT1` |

左环岛将MARK方向数字从1改0，即00、01、02，COMMIT方向改0。每次发送后等待相机实际回执，不连续快速粘贴整段命令。命令会自动切到第5页：第1通道为3代表处理成功，为4代表拒绝；第2通道为0代表成功，为1代表仍在等待，其余状态需处理拒绝原因。接收到转发请求并不等于照片或标定已保存。

RESET后只向前手推，发生倒退需RESET重采本轮。确认每个标记成功后再移动到下一位置，三次标记和提交均在停车、电机关闭状态完成。入口配置文件和照片在相机本地保存，切换另一代码版本时保留它们。

安装位置、镜头角度、编码器比例或赛道入口发生变化后需要重新标定。标定不能使用运行包里虚构的默认距离。每个方向单独记录、单独核验。

## 标定结果与诊断页

入口标定保存在OpenMV当前程序目录：`ring_visual_entry_calibration.json`和`ring_encoder_entry_calibration.json`；三处灰度图和元数据在相对目录`ring_entry_marks/`。同一次手推提交会分别保存两份配置，切换独立版本时保留这些文件。标定记录不随公开代码包发布。

逐飞助手第5诊断页，第1通道为请求状态（2等待、3成功、4拒绝），第2通道为相机真实回执（0成功、1等待）。COMMIT时第15通道为保存结果位图：1仅视觉配置成功，2仅编码器配置成功，3两份均成功；0均未确认。部分成功不能视作本轮标定全部完成。第16通道为执行器输出状态，手推时必须为0。
