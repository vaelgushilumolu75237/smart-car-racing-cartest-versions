# V30：采用“新A”的普通循迹速度，保留环岛控制

用户要求把速度降到工程中命名的“新A”。该档的速度为直道5.6转/秒、
弯道外轮4.4转/秒。本版只采用这两个普通循迹速度，不切换到会关闭
环岛的历史A协议档。当前无线、C配对、陀螺仪350°及出环动作继续使用。
速度为外轮软件目标，内轮按原Ackermann比例计算；中间请求在5600与
4400 milli-RPS之间插值，保留200ms减速、800ms加速。
默认无线轮速缩放为1000，实际配置的全局缩放仍在目标之后生效。

环岛独立目标继续为7392 milli-RPS。此前普通直道降速会同时降低PI
目标合法性上限，导致环岛目标被拒绝；本版使普通目标与合法性上限
分离。保留原配对C+40%的7840 milli-RPS校验上限，不扩大原上限。
验证真实增量PI接受7392目标，并拒绝7841目标；历史非无线构建维持
原目标和边界。没有把软件验证描述为实车环岛通过。

主控需用户手动烧录V30，Debug首项为
`Latest v30 | New A speed 5.6/4.4, gyro ring retained | Camera V29`。
相机配套V29；其连续环岛基准修复仍需单独确认实际安装。
本轮不上传相机、不烧录/复位H743、不启动电机。
