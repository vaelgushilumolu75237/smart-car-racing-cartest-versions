# 7.6完赛版

用户指定的版本名称，冻结日期：2026-11-14。本次发布不修改整车控制行为，不烧录、复位或启动车辆。

主档为 `DebugRingFastLimit2`，Debug 第一项显示为“7.6完赛版”。主控固件为 `build/DebugRingFastLimit2/CarTest.elf`，配套使用本包生产目录 `openmv` 和辅助红色检测目录 `k230_red_obstacle`。

| 参数 | 冻结值 |
| --- | --- |
| 普通直道轮速目标 | 7.6 圈/秒 |
| 普通弯道外轮目标 | 4.4 圈/秒 |
| 识别环岛后回中直行 | 700 ms |
| 入环、绕环外轮目标 | 7.6 圈/秒 |
| 环岛目标角速度 | 282°/秒，左右镜像 |
| 相机确认入环后的出环累计角度 | 280° |
| 环岛舵机偏转系数 | 相对中位 1.875 倍，保留原上下限 |
| 出环回中 | 1530 μs，达到软件中位后保持 300 ms |
| 出环阶段外轮基准 | 5.28 圈/秒 |

上述速度是控制目标，不表示电机在赛道上的实测轮速。已有寻迹、陀螺仪、无线控制、红色绕障和第三次黑色标记停车功能按当前程序保留。另有 C Base、极限测试档和独立架空测速档；架空测速档不能作为赛道固件使用。

OpenMV 本地生产包必须包含已有 `ring_width_calibration.json`，SHA256 为 `fa83b9b079dc8555365aa8f77b7fdc06f78955889eb2f0056788429c7d782f6c`。真实标定仅存本地交付目录，按项目要求不上传公开仓库。验证生成的 `.mpy` 仅作编译证据；部署使用配套 Python 源文件及标定。

K230 辅助红色检测保持 320×120、红色像素严格大于 4%（1536 像素）才触发；UART1 为 GPIO9 TX、GPIO10 RX，115200。绕障仍为左转30°、左前平均0.25圈、右转30°回正、跳过前行段、右转30°、右前平均0.25圈、左转30°回正。

已知限制：无线 START 可启动行驶，但当前行驶日志和 PI 轨迹的启动入口仍依赖 PE7 启动事件，因此无线启动的一次完整行驶未必保存轮速和 PWM 历史。本次仅冻结发布，保留该已知问题，不能据日志为空断言车辆没有行驶。本包不公开真实车辆日志或用户图片。

发布前完成当前源码交叉构建、对应主机回归及相机模块语法编译；这些检查不等于本版本完成实车赛道验收。
