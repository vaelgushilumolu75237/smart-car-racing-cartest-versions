# V27：普通转弯目标轮速降低20%

在当前 Wireless Gyro350 C +40% 控制档，将普通转弯全减速请求的
外轮目标由6160降为4928 milli-RPS，即6.160→4.928转/秒。
内轮继续按原Ackermann比例计算。中间请求在直道和新弯道目标之间插值。
保留原200ms减速、800ms加速过程。

直道目标仍为7840 milli-RPS。陀螺仪环岛状态机使用独立7392 milli-RPS
目标，仍由主循环覆盖普通循迹目标。350°、入出环动作和保护不改。
全局无线轮速缩放仍在上述目标之后生效；上述数字对应默认1000缩放。
历史非无线构建保留原目标。

相机程序保持已安装的V26。本次需要用户手动烧录新的H743 ELF：
`Install_K230_Turn_Speed_v27/H743/Wireless_Gyro350_C_Plus40/CarTest.elf`。
工程Debug第一项为 `Latest v27 | Turn speed -20% / camera V26 2M | Wireless C +40%`。

此次没有上传相机、烧录/复位H743或启动电机。
源码/构建验证不能证明实际车速已降低或赛道测试通过。
