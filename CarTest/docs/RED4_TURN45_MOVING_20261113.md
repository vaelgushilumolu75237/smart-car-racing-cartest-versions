# 红色4%与45度绕障，移动交还寻迹

K230保持320×120，红色实际像素严格超过1536（4%）发送一次R。等于1536不触发；框线未达阈值为蓝色，超过为绿色。

当前六个Debug档位保留，删除C独立预瞄95%/弯道110%档位，普通预瞄和弯道速度恢复原六档参数。历史不可变交付和备份保留。

绕障顺序：左转30° → 左前斜行左右轮平均1圈 → 右转45° → 跳过原第4段 → 右转45° → 右前斜行平均1.5圈 → 左转45°。角度均为各段相对转角，最终相对初始方向向右15°；未擅自修改第一段来抵消。

绕障结束后舵机回中、保持最后转弯段的轮速基准前行，连续3帧新鲜有效普通路线到达后交还原寻迹。C原速为4.400圈/秒基准，其他档按原比例；无线轮速缩放仍有效。切换不清零电机PI、输出或重走启动斜坡。通信/IMU/编码器/PE7/第三次黑标停车保护保留；未找回路线的移动等待沿用各档丢线期限（A/B为2秒、C为3秒），超时停车。

参数在Inc/obstacle_bypass_config.h，恢复逻辑在App/obstacle_bypass.c及App/obstacle_authority.c，红色阈值在k230_red_obstacle/red_detector.py。

手动更新K230_RED/red_detector.py（旧版升级可使用完整K230_RED目录），手动烧录本包相应H743 ELF。若相机装过独立C档，需将OpenMV/main.py和OpenMV/reverse_control.py更新为本包版本；更早版本升级使用完整OpenMV目录，保留用户标定文件。

本版完成软件回归、六档实际ARM构建及相机代码交叉编译；未自动上传相机、烧录/复位H743或启动电机，未实车验证绕障路线。
