# v26-r19：出口外边线引导候选

此前实现存在一个可以从源码复现的限制：出口确认/修复依赖双边普通路线；
即使出口外边线可构造中线，目标仍被环内冻结参考限制。另外，相机到主循环的
外边线证书只允许 INSIDE/EXIT_CONFIRM，修复和重新捕获阶段的外边目标会在
最终 UART 转换之前被拒绝。这些是实现缺口，不足以单独证明历次实车冲出的原因。

## 行为

- 仅在已经确认环岛、观测过出口缺口后，允许出口外边线形成独立证据。
  右环岛使用图像左侧外边线，左环岛镜像；不交换环岛身份或强制误差符号。
- 使用当前观测边和原标定逐行宽度构造中线。保留完整拓扑、近端、参考行、
  已知白色通道检查；缺失行不伪造，歧义、岛、分支、错误宽度和明显曲线不确认。
- 至少8行、纵向跨度12格，线形残差不超过4半格。连续3个新帧确认，间隔必须
  大于0且小于250ms。起始形状必须衔接最近真实发送的环内路线；之后的近端、
  参考位置和足够共同行也必须逐帧连续。中断后重新确认，不靠超时授权。
- 确认后的当前出口外边线可以引导转向、推进修复，不必等待双边同时出现。
  每帧都重新测量并重建中线；不能通过把旧误差标成有效新帧来实现维持转向。
  独立的新测量可以逐步偏离旧环内冻结参考，避免一直被旧参考锁住。
- 单边可继续引导 REACQUIRE；释放环岛身份仍需普通双边路线完成原有恢复检查。
  “沿出口中线回正”由原转向函数随当前误差变化实现，不直接输出舵机中位。
- 无线路时保留原 H743 的最后可信带符号偏差、200ms减速和2秒截止。
  无效帧不会延期；通信、档位配对、PE7和硬故障保护保持原样。
- 外边线证书覆盖 EXIT_REPAIR/REACQUIRE，并检查同帧、同对象、档位、会话、
  标定和连续性。新增 EXIT_CURRENT_SINGLE 原因码追加到表尾，串口和BIN布局不变。
- 新增1个60行整型数组，数据240字节，另有对象/属性开销。无运行中文件写入。
  新增代码的H750耗时、内存余量和IDE实际显示帧率仍待板端测量。

## 验证与边界

相机496项回归，零失败/错误，4项明确跳过。新增覆盖左右出口单边、三帧边界、
中断、过期/无发送、曲线、分支、未知通道、歧义、错误宽度、缺失标定、身份切换、
证书失效、单边修复及双边最终释放；普通弯和十字沿用独立负例回归。

实际主循环对镜像单边目标发出有效V3误差 -190/+190。真实H743解析和转向函数
得到1473/1659us；9项桥接向量通过。该证据不包含物理舵机动作。
H74372项/7713次断言及2秒保持/200ms减速检查通过；全部15个构建成功。
H743生产源码和配套A/B/C ELF与r18一致。

历史手推复核使用3轮443条稀疏记录和21张原图，检查当前几何构造。
部分原图仍缺少合格近端/参考位置支持，不会因为本次修改就变成有效路线。
旧记录未保存完整发送逐行参考，无法精确重放r19连续确认及最终UART时序。
新增RAM采集字段保留这些参考及单边拒绝原因，避免下轮再次缺证据。

23个运行模块及RAM采集脚本交叉编译验收单独保存。主模型亲自实施和审查，未委托。
相机固件、车辆H743、速度、增益及PE7未改；未上传、复位、烧录或启动电机。
