# V26：单边补线保留普通循迹资格

有效的 `single_left` / `single_right` 路线此前没有设置V4 ordinary位。
H743的陀螺仪控制档在非环岛阶段要求该位，因此相机即使算出有效
单边路线，主控也会拒绝驱动资格。此次仅将通过原有校验的左右单边
路线与 `road` 一并标为普通循迹；无效路线、环岛路线不获得该资格。
原有缓存、边界、连续性、时限、CRC和350°控制保护均保留。

## 安装范围

- 仅相机 `main.py` 的路线分类发生变化；主控源码和20套配对ELF不变。
- 已烧录V25 H743时无需重烧。完整安装包仍保留配对H743文件供恢复。
- 更新现有相机包时只替换 `/sdcard/cartest-k230/main.py`；保留
  现场 `ring_width_calibration.json` 和其他配置。
- 本轮未安装生产相机程序、未烧录/复位H743、未启动电机。
- 相机只读诊断在RAM执行，未修改SD卡文件；SDK在诊断退出时报告
  soft reboot，不把它描述为相机始终连续运行。

## 验证与范围

新增测试调用真实双边→单边→双边主循环、解析器和补线器；旧代码
在有效单边帧的ordinary参数处失败，修正后通过。
527项算法回归、55项适配层测试、15项陀螺仪相机测试、12项无线相机
测试通过，33个相机模块完成便携字节码编译。
复用V25的实际主控构建，逐项核对主控源码和全部ELF哈希。

这些证据证明路线资格传递缺陷的软件修正；不证明弯道连续补线、
最终安装后的帧率或赛道表现通过。现场另有视觉超时/协议异常，
其全部因果关系尚未确认。真实车上日志和标定不进入公开检查点。
