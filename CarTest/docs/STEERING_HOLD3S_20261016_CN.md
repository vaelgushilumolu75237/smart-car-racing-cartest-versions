# 3秒偏差保持与转向链路诊断

相机版本为 `STEERING_HOLD3S_20261016`。这次固定普通循迹视觉算法及快速转向70%/30%档的参数，补充链路证据；不把延长丢线续行当作已修好弯道。

## 丢线行为

仅已经启动、完成首次完整PWM且两轮实际已有输出的Follow会话允许保持。保持值是H743最后接收并认可的有效 `error_norm`，不是无效帧中必须发送的零偏差。

舵机继续以该偏差对应的原目标脉宽运行，仍经过1100～2500μs限幅和既有变化限制。如果目标1900μs、实际只有1600μs时丢线，继续受限趋近1900μs；不再把1600μs固定下来。左右电机分别保持丢线入口时的实际占空比，不重新计算差速，不加速。

期限从最后可靠帧的接收时刻计算3000ms。零散有效帧不延长期限；连续3帧新鲜有效路线才恢复。到期关闭输出并保留会话等待恢复；到期后恢复重新经过首个完整PWM与电机启动保护。PE7再次按下取消会话并停车。无数据250ms、UART、协议、序号及硬故障仍先停车，不等待3000ms。

快速档正常舵机变化限制仍为60μs/20ms，启动和到期后恢复仍为10μs/20ms；增益0.7、直线50%/50%、最大差速70%/30%及70%输出保护均不调高。

## 相机诊断记录

本次诊断发布版默认 `STEERING_DIAG_ENABLED = True`。只有一套主视觉程序，没有重新制作裁剪中点对照版。设为False可关闭记录，关闭时不分配记录缓冲。

记录使用固定128条×32字节RAM环形缓冲，不逐帧打印。保存实际打包帧序号、相机时刻、有效标志、位置/预瞄项、实际发送偏差及UART写入结果；满时覆盖最老记录并累计覆盖次数。成功发送的有效帧首次变为成功发送的无效帧后冻结，保留该无效帧。冻结诊断记录不会停止图像处理或UART发送。相机复位、断电或重新运行脚本会清除这份RAM记录。

把车放在可识别的直道后运行相机；如果发车前已经发生有效→无效，诊断可能提前冻结，不能将其冒充本次行驶记录。需要重新开始相机脚本并确认取景稳定，再开始一次测试。

采集后先按PE7停车，保持H743及相机通电。在OpenMV IDE停止脚本，**不复位解释器**，在REPL输入：

```python
steering_diag_dump()
```

把从 `STEERING_DIAG_BEGIN` 到 `STEERING_DIAG_END` 的完整文字保存为电脑上的文件，例如 `D:\相机诊断.txt`。记录包含相机计时回绕周期；不能直接把相机时刻与H743时刻相减当作通信延迟。

## H743日志与入口快照

H743单独保存最近一次丢线入口的可靠偏差、序号、接收时刻、入口时刻、目标/实际脉宽及左右实际占空比，停车后仍可通过Hot Plug状态读取。快照只代表最近一次入口，须按时间和序号对应；不能套用到所有历史入口。

日志头与记录仍各64字节，语义版本为V2。V2保持时长以50ms刻度编码0～3000ms；实际停车判断仍使用毫秒计时，不是50ms才检查一次。新解析器继续支持V1的20ms刻度。原 `vision_latest_error_norm_milli` 仍表示最新收到的帧，不能把其中的无效零值当作保持值。

先手动烧录本版配套 `build/DebugFollowTurn/CarTest.elf`，相机另行上传整套20个顶层Python文件并重启。只有编译和文件校验并不证明已经烧录。旧RAM记录必须使用其对应旧ELF。

跑完按PE7停车，保持H743通电，不按F5、不复位，再连接ST-Link并执行：

```powershell
cd "D:\Codex\smart-car-racing-codex-handoff\smart-car-racing\firmware\vehicle\CarTest"
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\tools\export_run_log.ps1" -Elf ".\build\DebugFollowTurn\CarTest.elf" -ConnectionFrequencyKhz 1000 -SharedConnection
```

成功输出行驶CSV，并附状态/入口快照报告。若日志是IDLE，导出应报告版本、日志开关、启动事件、运行时间及复位状态；不生成空CSV作为成功结果。状态报告的实际路径以导出输出和 `run-metadata.json` 为准。

离线分析命令：

```powershell
python .\tools\analyze_steering_chain.py --camera-trace "D:\相机诊断.txt" --h743-csv "D:\本次日志目录\run.csv" --status "D:\本次状态目录\run-status.json" --out "D:\本次转向分析"
```

分析只生成对照表和报告，不写固件或启动车辆。按帧序号核对相机发送值、H743接收值、目标、受限和实际PWM；未匹配、时钟或会话有歧义时标为未知，不推算成确定接收结果。PWM记录是软件/寄存器输出，不是机械转角测量。

## 验证及用户实测

软件验收覆盖2999/3000ms、计时回绕、连续无效帧、零散有效帧、三帧恢复、250ms通信故障、PE7停车、舵机未到位时保持偏差，以及V1/V2解码、CRC、64字节布局、相机记录冻结与覆盖。最终构建、退出码和哈希报告随交付保存。
