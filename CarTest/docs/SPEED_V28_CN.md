# V28：直道目标降低20%，弯道目标降低10%

以V27为基准，当前无线 C +40% 档的普通循迹外轮目标：
直道7840→6272 milli-RPS，普通弯道全减速请求4928→4435 milli-RPS，
四舍五入至整数 milli-RPS。内轮仍按原Ackermann比例计算。
中间减速请求在这两个端点之间插值；沿用200ms减速和800ms加速。
无线轮速缩放在上述目标之后生效，数字对应默认1000缩放。

陀螺仪环岛使用独立的7392 milli-RPS目标和原350°、出环动作。
历史非无线构建继续使用原速度。相机程序沿用V26，无需重装。
用户需手动烧录V28 H743 ELF，Debug首项名称为
`Latest v28 | Straight -20%, turn -10% / camera V26 | Wireless C +40%`。

这次没有上传相机、烧录/复位H743或启动电机。速度为轮速软件目标，
实际车速和赛道表现尚未测量。真实日志及标定不进入公开检查点。
