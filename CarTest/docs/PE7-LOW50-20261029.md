# v22 PE7 low qualification extended to50ms

The user requested longer low-level debounce after a board read captured a new start followed181ms later by a high-level stop event. Current-low WAIT_HIGH correctly preserves the requested stop/rearm latch. That read proves the firmware observed high, not whether the cause was contact bounce, interference or another electrical source. Extending low qualification is not proof of fixing that high-level disturbance.
