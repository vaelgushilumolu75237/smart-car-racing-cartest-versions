# 环岛500ms与红障5%参数版

基于上一版实机启动显示修复继续修改。本版仅完成软件验证，不自动上传相机、烧录或复位H743、不启动电机。

## 本次参数

- 原条件识别环岛后：1530μs回中直行500ms，再由陀螺仪接管转向。
- 入环、绕环外轮目标在上一版基础上再降低50%。B=1.500、C=1.980、C+20%=2.376、C+30%=2.574、C+40%=2.772圈/秒。A不开启环岛。
- 入环、绕环舵机偏转量在上一版基础上乘1.5；上一版相对原控制输出的1.25倍改为1.875倍，即1875‰。仍以1530μs为中位，输出仍限在1100～2500μs。此值不是机械转角。
- 环岛目标角速度、350°退出门限、回中300ms出环和普通道路速度不变。无线轮速缩放仍会影响最终目标。
- K230全幅320×240红色像素严格大于3840（5%）触发；等于3840不触发。连续事件仍只发送一次R。
- 先统计原始图像、发送R，再在独立640×480预览上为每个红色连通区域绘制矩形。整幅红色占比≤5%时用蓝框，>5%时用绿框。多个区域仍合计实际像素，不用框面积触发；无红色区域时无框。
- 红障固定绕行第4段由左右轮平均前进3圈改为1圈。其他六段、角速度、各段超时和当前档直道/弯道速度不变。路线仍是待实车调参的候选值。

## 安装位置

H743：当前工作区Debug六个档位均已重构建，或使用交付包H743对应档位的CarTest.elf。请人工烧录。

K230：K230_RED目录中的main.py、settings.py、red_detector.py放入/sdcard/cartest-k230/。startup.py是根目录启动器的源文件；仅在修复启动入口时，将它复制为/sdcard/main.py，不要覆盖子目录内的识别main.py。此前已修正的根目录启动器无需重复替换。本次新增蓝绿框及5%门限必须更新相机这三个文件才生效。

OpenMV：源码未变，继续使用原配套25文件包；之前ST-Link发现的旧V3实际运行问题需独立确认，本次参数修改不会让旧V3程序自动变为V4。

接线仍为K230 GPIO9 TX→H743 PC11 UART4 RX、GND共地。GPIO10只做固件RX映射，无需外接。

参数与实现：Inc/gyro_ring.h、App/gyro350_authority.c、Inc/obstacle_bypass_config.h、k230_red_obstacle/red_detector.py及main.py。Debug显示名称同步更新。

检查包含严格5%边界、单次事件、蓝绿框坐标/颜色、绘图在检测后执行、UART初始化、六档状态机、环岛500ms前后边界、舵机限幅、原OpenMV与无线回归，以及六档真实ARM构建。详见validation/software-validation.json。无实车绕行或新画框实机验收结论。
