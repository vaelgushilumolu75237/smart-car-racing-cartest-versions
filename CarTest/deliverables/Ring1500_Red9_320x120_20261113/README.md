# 环岛1500ms与320×120红障9%参数版

本版基于上一版，仅修改用户指定的以下参数：

| 项目 | 当前值 |
|---|---|
| K230识别分辨率 | 320×120，共38400像素 |
| 红色触发 | 实际红色像素严格大于3456，即超过9%；3456不触发，3457起触发 |
| 蓝绿框 | 所有红色区域总像素≤3456用蓝框，>3456用绿框 |
| 环岛识别后回中直行 | 1530μs保持1500ms，再进入陀螺仪转向 |
| 绕障左前斜行，第2段 | 左右轮平均前进1圈 |
| 绕障向前越障，第4段 | 保留左右轮平均前进1圈 |
| 绕障右前斜行，第6段 | 左右轮平均前进3圈 |

红色识别仍统计全幅所有区域实际匹配像素，无额外形状、距离或连续帧条件；连续事件仅发一次R。先识别发送，再在独立预览上画框。屏幕仍为640×480，320×120画面按比例放大为640×240，垂直居中，保留上下黑边，不把预览尺寸作为识别尺寸。

环岛速度、舵机系数保持上版：B=1.500、C=1.980、C+20%=2.376、C+30%=2.574、C+40%=2.772圈/秒；A不执行环岛。入环和绕环相对中位的舵机偏转系数1875‰，保持1100～2500μs限位。350°出环、回中后300ms、原角速度和普通循迹速度不变。环岛入环总超时仍4秒（从识别起计，包含1500ms直行），通信与IMU保护保留。

绕障四次转弯仍各30°，转弯速度用本档弯道目标，三段前进用本档直道目标；角速度、段超时、路线恢复及绕障优先级均未改变。路线距离是平均车轮圈数，不是米。候选路线仍需实车调参。

## 安装

H743：烧录当前工作区Debug所选档位，或本包H743对应目录的CarTest.elf，六档均已真实构建。

K230：将K230_RED/main.py、settings.py、red_detector.py三个文件替换到/sdcard/cartest-k230/，随后人工重新上电。startup.py为SD卡根目录启动器源文件，已正常启动的相机无需改动该入口。GPIO9 TX→H743 PC11 RX，共地，115200/8N1。

OpenMV：本次未改源码，不需要因此更新。K230只负责红障，OpenMV继续负责寻迹和环岛识别。

参数位置：Inc/gyro_ring.h、Inc/obstacle_bypass_config.h、k230_red_obstacle/settings.py及red_detector.py。

## 验证边界

软件验证覆盖3456/3457边界、320×120几何与拒绝旧240高度、居中蓝绿框、单次事件、1/1/3圈路线切换、1500ms入环等待边界、六档控制接管、原OpenMV/无线回归和ARM构建。细节见validation/software-validation.json。本次没有自动写相机、烧录/复位H743或启动电机，尚未实机验证新分辨率和赛道行为。
