# v26-r17 C档环内小幅提速候选

保留r16出环准入保护。按用户新增要求，仅将C档已确认INSIDE、且非入环
过渡路线的减速请求从1000改为667。配套H743的5600/4400 milli-RPS端点
经原函数整数运算得到4800 milli-RPS，外轮目标由4.4提高到4.8转/秒，
约提高9.1%。这是轮速目标，不是实测车身速度。

B档、普通道路/普通弯、入环过渡、EXIT_CONFIRM/EXIT_REPAIR/REACQUIRE
仍沿用原请求。无效路线不携带有效速度请求。未知状态不提速。
不改控制串口、档位配对、PE7、故障保护或H743源码/ELF。
实际H743 ackermann_control.c主机编译检查确认左右镜像轮速、667=4800、
1000=4400，以及800ms加速/200ms减速斜坡。相机测试检查最终V3包字段。
