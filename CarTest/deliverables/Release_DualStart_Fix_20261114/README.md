# 7.6终极版双启动修复

PE7第一次按下产生本地启动请求时，无线控制模块原先将按键低电平解释为全车停止，并在每次服务时重复停止、复位相机控制会话。该冲突会清除本地启动请求并阻碍相机握手恢复。

修复后，普通行驶的PE7启动/停止由原有按键边沿逻辑负责。无线模块在按键未释放或上电释放未确认时撤销无线启动请求；仅在无线执行器测试正在进行时额外发出停止。无线STOP和硬故障停止保留。两种启动仍经过原有路线、IMU、编码器和通信门控。

主配置仍为DebugRingFastLimit2，直道7.6圈/秒，弯道5.1圈/秒；环岛外轮7.6圈/秒、目标角速度282度/秒、识别后直行700ms、出环角度280度。相机代码与既有标定不变。

修改：App/wireless_control.c、对应无线核心及运行时回归测试、Debug显示名称。旧实现会在新增PE7回归测试中失败；修复后通过。实际构建和软件检查见配套validation。诊断工具原有8192字节跨度限制导致本次常规读取失败，现场采用有界只读RAM读取并校验Flash描述符；未修改诊断工具。

软件测试不能代替实车验证。此次不烧录、不复位、不启动电机。仅需用户烧录新的H743固件，相机无需重新上传。D:\7.6终极版历史归档保持不变。
