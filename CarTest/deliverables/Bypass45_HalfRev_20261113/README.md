# 绕障四次45度，两段斜行各半圈

基于红色4%与移动恢复版本，仅调整首次左转及两段斜行行程。

执行顺序：左转45° → 左前斜行左右轮平均0.5圈 → 右转45° → 跳过原第4段 → 右转45° → 右前斜行左右轮平均0.5圈 → 左转45°。四次相对转角合计为0°，目标朝向回到初始方向。

各段速度、60°/秒转弯目标角速度、超时与原安全保护保持；C原速转弯外轮4.400圈/秒，斜行5.600圈/秒，其他档按原档位比例。绕障结束保持末段速度前行，收到连续3帧新鲜有效普通路线后交还寻迹，不主动停车、不清零电机PI或重新启动斜坡；等待超时和故障仍停车。

红色检测仍为K230 320×120、严格超过1536像素（4%）触发。原六档保留，独立C档不恢复。第三次黑标离开后1秒锁定停车、环岛功能保持。

本次只需手动烧录对应H743 ELF；已安装上版红色4%程序的K230及上版OpenMV无需重复更新。包内相机程序为配套原文件，保留用户标定。

修改：Inc/obstacle_bypass_config.h、tests/obstacle/test_obstacle.c及本说明。六档实际ARM构建、绕障状态机及控制权限回归通过，未自动烧录、复位、启动电机，未实车验证路线。
