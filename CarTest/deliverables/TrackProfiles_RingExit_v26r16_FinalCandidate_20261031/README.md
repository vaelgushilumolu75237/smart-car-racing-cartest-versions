# v26-r16：出环路线准入候选

本版针对 r15 实车出环前先回正、随后丢线的风险增加相机侧保护。
现有 H743 日志可确认偏差及舵机输出先减小，再进入丢线续行；
缺少对应 r15 相机 BIN，尚不能证明当时具体用了哪条边界或处于哪个视觉状态。
用户已确认相机测试前全部断电重启，不能把失败归因于未重启。
本版未安装到相机，未进行实车或板端性能验收。

## 修改

- 内边界优先，使用当前观测边与标定逐行宽度推算中线，左右镜像。
  外边界仍须通过原有支持、拓扑、走廊、宽度及切换检查。
- 将可信路线提交移到最终有效 V3 整包写入成功之后。预算超时、
  档位/会话失效、无效包及短写均不能刷新路线历史。
- 环内最后成功发送路线的逐行几何在出环期间冻结。
  当前出环目标的所有参与行必须有对应参考，位移不超过原有 12 个半格；
  同时要求近端和参考行支持。连续的小步偏移不能不断移动冻结参考。
- 独立的当前双边普通路线连续通过现有 4 帧检查后，可以授权真正的出口。
  增加逐行形状连续性检查，不能仅凭一个参考点稳定就接管。
  候选目标还必须逐行匹配该当前双边观测。偏差减小本身不是拒绝条件。
- 保护只用于标定启用的 EXIT_CONFIRM / EXIT_REPAIR / REACQUIRE。
  不重放旧路线或旧偏差为有效帧。被拒绝时发送无效帧，由原有 H743
  2 秒丢线续行处理；不延长其截止时间。
- 新增三个诊断原因：EXIT_GUIDANCE_UNTRUSTED、
  EXIT_CURRENT_PAIRED、EXIT_ANCHORED_CURRENT_EDGE。BIN 字段布局及控制协议不变，
  新增原因码附加在原表尾部，旧码不变。使用配套解码器读取新原因。

H743 源码、配套 ELF、PE7 原版切换、普通弯映射、速度和增益、
200ms 减速、2 秒续行、档位配对及硬故障保护保持不变。
新增两个固定 60 行 int 数组，数据区共 480 字节，另有对象/属性开销；
无逐帧文件写入。实际内存余量及增加的板端耗时仍待测量。

## 验证

- 473 项相机主机回归，零失败/错误，3 项既有跳过。
  缺少私有 RAW 的指定回放用例仍明确排除，不能算通过。
- 新增左右镜像、小步累积偏移、正确出口变直、证据中断、
  参考点相同但其余行改变、过期/缺失参考、短写/无效/重复提交、
  环内行为、最终 UART 有效位及发送后提交测试。
- 23 个生产模块通过 MicroPython 1.28 armv7emsp 交叉编译。
- H743 主机回归 72 项、7,713 次断言，零失败。
- 15 个预设增量构建均成功；H743 源码和配套 A/B/C ELF 与修改前逐字节核对。
  不是新增控制固件，也没有烧录/复位 H743。
- 主模型亲自实现并审查生产变更；本轮未使用子代理。

## 限制和后续

这是软件测试候选，不能声称已经修好实车出环。普通道路、十字、
左右环岛入环/环内/出环均须实车回归。手推及合成几何不能替代实车。
IDE 开预览时实际超过 60 FPS 尚未验收，主机耗时及 UART 接收率均不能代替。

冻结参考沿用原有 2 秒最大年龄；单边目标若超过位移/行支持/年龄范围，
且双边出口尚未连续确认，将保持无效并可能触发既有停车。
这项保守限制可能造成提前减速停车，必须在受控路测中检查。
本版没有依据缺失的原始帧重建 r15 精确视觉过程，也未解决实车 BIN
未落盘的未明原因；现有 USB 输出只是性能统计，没有持久化错误证据。
所有私有视频、实际日志、原图和标定留在本地，不进入公开 checkpoint。
